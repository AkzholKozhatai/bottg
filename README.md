# Telegram Scheduler

Python-проект: бот-пульт (aiogram) + пользовательский Telegram-клиент (Telethon) + SQLite.

## Важно
- Используй только в чатах, где автоматические сообщения разрешены и ожидаемы.
- Минимальный интервал — 5 минут, число отправок ограничено 100.
- Не используй проект для массовых рассылок или обхода ограничений Telegram.
- `TELETHON_SESSION` — секрет, который даёт доступ к аккаунту. Не публикуй его и не коммить `.env`.
- На бесплатном Render локальная SQLite может потеряться при пересоздании/перезапуске сервиса. Для надёжного постоянного хранения нужен внешний PostgreSQL или хостинг с persistent disk.

## Подготовка сессии Telethon
1. Установи Python 3.11+ на своём компьютере.
2. Установи зависимости: `pip install -r requirements.txt`
3. Получи `api_id` и `api_hash` на https://my.telegram.org
4. В терминале задай `API_ID` и `API_HASH`, затем запусти `python setup_session.py`.
5. Введи номер телефона, код Telegram и пароль 2FA, если включён.
6. Скопируй выведенную строку как значение `TELETHON_SESSION`. Не делись ей.

## Настройка бота
1. Создай бота через https://t.me/BotFather и скопируй токен.
2. Узнай свой числовой Telegram user ID у надёжного ID-бота.
3. Залей файлы в GitHub.
4. На Render создай Background Worker из репозитория.
5. Добавь переменные окружения `BOT_TOKEN`, `API_ID`, `API_HASH`, `OWNER_ID`, `TELETHON_SESSION`.
6. Запусти сервис и напиши боту `/start`.

## Локальный запуск
Задай переменные окружения из `.env.example` в своей системе, затем:
`python main.py`
